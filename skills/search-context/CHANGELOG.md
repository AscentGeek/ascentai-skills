# lm-search-context 변경 이력

버전은 `SKILL.md`의 `metadata.version`과 배포 파일 이름(`lm-search-context_v<버전>.skill`)을 함께 올린다.
- 패치(1.0.x) · 문구·버그 수정, 결과 형식 변화 없음
- 마이너(1.x.0) · 분석 항목이나 리포트 구성 추가·변경
- 메이저(x.0.0) · 데이터 호출 방식이나 입력이 바뀌어 이전 산출물과 호환되지 않음

## v2.11.1 · 2026-11-25
- 근거 표기: 페이지 안 경로 분석과 마케팅 할 일의 근거를 `E2-AI` `E3-1` 같은 번호 대신 「키워드」 AI 개요, 「키워드」 검색 결과 N위(사이트명)처럼 출처를 말로 쓰게 함. 페이지의 SERP 원문에는 번호가 보이지 않아 번호만으로는 출처를 찾을 수 없었음
  - `scripts/sc.py` 경로 분석 지시문(Claude · ChatGPT 요청문), `references/workflow.md` Step 5

## v2.11.0 · 2026-11-24
배포판. 아래 v2.10.0~v2.10.3 변경을 묶었다(스킬 평가 2026-11-24 실패 항목 수정 포함).
- 경로 수 100 · 200 · 300을 시장·언어와 함께 묻고 기본은 300, 받은 경로를 모두 분석에 씀
- MCP 호출 규약: `skill_desc` · 개인정보가 있으면 멈추고 다시 요청 · 실패한 호출 대응 · 호출은 한 번에 하나
- 시드 표기가 경로 데이터와 띄어쓰기만 다르면 데이터 표기로 맞춤
- 리포트를 만들 때 받은 SERP를 페이지가 다시 씀
- 비용 안내: 리포트 1건 약 5 Lima · 경로 분석은 SERP 1개당 0.1 Lima

## v2.10.1 · 2026-11-24
스킬 평가(2026-11-24)에서 실패한 MCP 호출 규약을 고쳤다. 결과물 형식은 같다.
- **`skill_desc`** 절 추가: 모든 호출에 `{"name": "lm-search-context", "version": "<버전>"}` 객체를 보낸다(캐시 키 제외 · `mcp_cache.py`도 키에서 뺌)
- **개인정보 규칙**: 요청에 전화번호 · 이메일 · 신분증·카드·계좌 번호가 있으면 MCP를 부르기 전에 멈추고 다시 요청받는다(Step 0 첫 확인). 스스로 가린 문장으로 진행하지 않는다
- **실패한 호출** 절 추가: Too Many Requests(한 번 재시도) · Insufficient Lima · Account Locked · Not Authenticated · 서버 오류별 대응, 사유를 그대로 전함
- **호출은 한 번에 하나**: MCP 동시 호출 금지, `serp`도 차례로
- `mcp_cache.py store`가 `result`가 OK가 아닌 응답을 거부한다
- 사용자가 준 API 키는 쓰지 않는다는 문장을 전제 조건에 명시
- `plan`: 시드가 경로 데이터와 띄어쓰기·대소문자만 다르면(예: 캠핑의자 ↔ 캠핑 의자) 경로 데이터의 표기로 맞추고 알린다(전에는 「지나는 경로가 없습니다」로 멈춤)

## v2.10.0 · 2026-11-24
- **경로 수(PATHS)를 사용자가 고름**: Step 0에서 시장·리포트 언어를 물을 때 경로 수 100 · 200 · 300도 함께 묻는다. **기본 300**(묻지 않았거나 고르지 않으면 300)
- `path_finder`의 `limit`을 PATHS로 넘기고, 받은 경로 전부를 요약·마케팅 분석·처음 맵에 쓴다(`plan --show <PATHS>`, `SHOW_DEFAULT` 100 → 300)
  - limit이 다르면 서버가 돌려주는 경로 묶음이 다르다(실측: limit 100과 limit 300의 앞 100개 중 같은 경로 71개). 다른 limit 응답을 잘라 쓰지 않는다
- 페이지의 「경로 100 / 200 / 300」은 받은 범위 안의 값만 보이고, 하나뿐이면 숨긴다
- 비용 안내에 경로 수를 함께 적는다(경로 수를 바꿔도 호출 횟수는 같음)

## v2.9.0 · 2026-11-24
- **실행 도구별 HTML** (`render --host claude|chatgpt`, 기본 `auto`): 스킬을 실행하는 LLM이 HOST를 스스로 정해 넘긴다
  - `chatgpt`: 「경로 분석」과 질문이 경로 데이터를 담은 **요청문 복사**로 동작(ChatGPT 대화창에 붙여 넣기). 경로 분석 요청문은 ChatGPT가 ListeningMind 커넥터 `serp`로 SERP를 조회하도록 지시
  - `chatgpt`에서는 Claude 연결·권한 안내, 저장된 분석, 대화 기록 저장을 빼고 버튼·안내·하단 문구를 ChatGPT 기준으로 바꿈
- `render --lm-server`: ListeningMind 커넥터의 표시 이름을 넘김(계정마다 이름이 달라 `server_not_connected`가 나던 문제)
- 맵의 **빈 공간 클릭으로 선택 해제**(드래그 이동 제외, 경로 분석 중에는 유지)
- 호버 카드의 **Target 키워드를 테두리 칩**으로 바꿔 「이 경로 분석」 버튼과 구분
- `check_report.py`가 HTML의 HOST에 맞는 기능만 확인하고, chatgpt 리포트에 Claude 안내가 보이면 ✗
- ChatGPT 실행 시 데이터 받기: 외부 네트워크가 막혀 있으면 처음부터 json 본문으로 받음(workflow.md)
